# pentomino.a60

The pentomino puzzle for the boxes 6×10, 5×12, 4×15 and 3×20. The program reads the
pieces and the box from the input, [pentomino6x10.in](pentomino6x10.in) and the like.

```
$ algc pentomino.a60 -o pentomino
```
